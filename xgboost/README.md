# xgboost/ — Critical-property prediction (Tc, Pc, omega)

## Validated pipeline (Frozen Protocol v3) — the production/thesis-grade result

`XGBoost.ipynb` cells 1-4 are Scripts 01-03 of the frozen protocol; `04_tc_outlier_audit.py` through `07_export_refrigerant_predictions.py` are the later read-only diagnostic and export stages. Run in order:

| Stage | What it does | Consumes | Produces |
|---|---|---|---|
| `XGBoost.ipynb` cell 1 (`01_prepare_data.py`) | Canonicalizes SMILES, builds RDKit-2D + Morgan(r=2, 2048-bit) features, frozen Butina-cluster 80/10/10 split, leakage-filtered estimated pool, OOF-predicted-Tb auxiliary feature | `data/final_master_experimental_finetuning_6644.csv`, `data/final_pretraining_estimated_critprop.csv`, `data/molecules_144_refrigerant.xlsx` | `artifacts/` |
| cell 2 (`02_train_variants.py`) | Trains XGB-A/B/C/D ablation variants per target | `artifacts/` | `results_v3/variant_test_*.csv`, `results_v3/XGB-*.json` |
| cell 3 (`03a_analysis_plots.py`) / cell 4 (`03_predict_refrigerants.py`) | Analysis plots; final 142-refrigerant deployment predictions (25-seed ensemble) | `results_v3/` | `results_v3/plots/`, `results_v3/refrigerant_142_final_predictions.csv` |
| `04_tc_outlier_audit.py` | Read-only: classifies worst Tc errors as SYSTEMATIC vs MODEL-SENSITIVE | `results_v3/` | `results_v3/tc_outlier_audit/` |
| `05_refrigerant_domain_audit.py` | Read-only: how well the 142 refrigerants are covered by training data | `results_v3/` | `results_v3/refrigerant_domain_audit/` |
| `06_domain_weighted_xgboost.py` | Controlled ablation: does domain-aware reweighting of estimated Tc data help refrigerant-like molecules (D0-D4)? | `artifacts/`, `results_v3/` | `results_v3/domain_weighting_experiment/` |
| `07_export_refrigerant_predictions.py` | Final Tc (3 recipes) + Pc/omega export for the 142 refrigerants, for the COP project | all of the above | `results_v3/final_refrigerant_predictions/` |

**Model selection** (`results_v3/analysis_v2/07_model_selection.json`): XGB-D lowest RMSE for Tc/Pc; XGB-C nominally lowest for omega but statistically indistinguishable from XGB-D on this frozen split. See `docs/validation.md` for the full negligibility-resolution methodology and its limits.

Excluded from git: `artifacts/X_benchmark.npy`, `X_est.npy`, `X_142.npy` (Morgan+RDKit2D feature caches, tens of MB, deterministically regenerated by cell 1). Everything else in `artifacts/` (manifest, feature names, the 5.3MB Tb model, split assignments) is small and kept for reproducibility without needing to re-run cell 1.

## `results/` — diagnostic experiments on a separate, larger dataset (NOT deployment models)

Built from `data/unique_molecules_Tc_Pc_omega*.csv` (union of finetune+Yaws, 7,829 molecules) — a broader but noisier dataset than the curated frozen-v3 benchmark above. These three experiments exist to answer "does more data help, and why/why not" — **none of them are deployment-ready**; treat them as a methodology investigation, not a replacement for the Frozen Protocol v3 models.

| Experiment | What changed vs frozen-v3 | Test RMSE (Tc / Pc / omega) |
|---|---|---|
| `unique_molecules_xgboost/` | Same methodology, larger/broader molecule set, finetune-priority labels | 38.58 / 5.74 / 0.078 |
| `unique_molecules_yawspriority_xgboost/` | Same as above but Yaws value preferred over finetune wherever both exist | 38.07 / 5.11 / 0.078 |
| `unique_molecules_splitfix_xgboost/` | Same as `unique_molecules_xgboost/` but caps any Butina cluster at 200 molecules (recursively re-clustered if larger) — fixes a 1,512-molecule homologous-chain super-cluster that dominated the train split and destabilized cross-validation | **24.65 / 4.30 / 0.069** — beats the curated XGB-A benchmark (31.17 / 3.57 / 0.083) on Tc and omega |

Each experiment's `audit/` subfolder is a full read-only diagnostic (label-source breakdown, cluster-composition analysis, chemical-family error patterns, refrigerant-leakage re-verification) — see `00_AUDIT_LOG.txt` in each. Their trained model `.json` files are **excluded from git** (regenerate with the corresponding training script — not included in this initial commit; see `docs/reproducibility.md`).

**Headline finding:** the mega-cluster split defect, not label noise, was the dominant cause of the initial degradation on the larger dataset — fixing only the split closed most of the gap to the curated benchmark.
